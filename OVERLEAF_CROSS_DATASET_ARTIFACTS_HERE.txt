OVERLEAF CROSS-DATASET ARTIFACTS
================================

Folder name (case-sensitive):

  OVERLEAF_CROSS_DATASET_ARTIFACTS/

This directory is part of the GitHub repository (branch: main).

After cloning or pulling:

  git clone https://github.com/iyadsec/fleet-can-ids.git
  cd fleet-can-ids
  # artifacts are already in OVERLEAF_CROSS_DATASET_ARTIFACTS/

Optional sync helper (macOS/Linux):

  bash scripts/sync_overleaf_artifacts_mac.sh

Contents: PDF/PNG figures, TeX/CSV/MD tables, reports, README, ARTIFACT_INDEX.csv.

Regenerate from repository root:

  python scripts/regenerate_paper_artifacts.py

See also:
- OVERLEAF_CROSS_DATASET_ARTIFACTS/README.md
- docs/paper_pipeline.md

GitHub: https://github.com/iyadsec/fleet-can-ids
